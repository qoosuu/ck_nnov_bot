# Проверка обновления · 3 октября 2026

Проверено локально на Python 3.12 / aiogram 3.13.1 / aiohttp 3.10.11.

35 автоматических проверок прошли: предметная логика, HTTP API, пересылка медиа и команды через маршрутизатор aiogram.

Покрыто:
- границы смен в 00:00, 01:00, 02:59 и 03:00;
- обязательные и необязательные поля, разрешённые пересечения;
- пустой дайджест, поздняя первая бронь, сводка будущей смены;
- создание, изменение, перенос, удаление и журнал действий;
- повтор запроса без дублирования брони, конфликт версий;
- ручная сводка, изменение часа, сохранение отметок после перезапуска;
- повтор доставки после ошибки, сохранённая очередь;
- проверка подписи Telegram, просроченных/подменённых данных;
- владелец, сотрудник, вышедший/заблокированный участник, исключение ботов;
- персональная кнопка меню, дедупликация открытий приложения;
- /iamworker: повторная проверка уже известного пользователя, вступление и выход из чата, запрет обхода ручной блокировки, работа без никнейма;
- /register и /register@имя_бота, запрет регистрации посторонним и в форуме;
- прежняя пересылка фото, видео и кружочков, восстановление удалённой/закрытой темы.

Браузерная проверка: изолированный Brave/Chromium через Playwright, ширина 390 и 1280 пикселей. Проверены все 17 столов, отсутствие горизонтального переполнения на мобильном, создание/изменение/удаление ночной брони, смена даты, настройки владельца, управление доступом, ручная сводка, экран без авторизации и интерфейс сотрудника. Ошибок JavaScript нет.

Снимки в `previews/` содержат только вымышленные записи локального стенда. Настоящие сообщения Telegram не отправлялись. Боевой сервер не изменялся. После установки нужно пройти короткую проверку из README с реальным ботом.
