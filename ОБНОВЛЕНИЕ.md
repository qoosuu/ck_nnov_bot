# Отдельные темы для пользователей

При первом фото, видео или кружочке бот создаёт в GROUP_CHAT_ID тему «Имя @username». Если никнейма нет — «Имя · ID 123456». Следующие файлы этого человека идут в ту же тему. Название берётся на момент создания; изменение профиля не создаёт другую тему. Подписи «От: ...» у фото и видео сохранены. Кружочки определяются по теме.

Соответствия хранятся в topics.sqlite3 рядом с bot.py и переживают перезапуск. Не удаляйте этот файл, сохраняйте его в резервных копиях. Путь можно изменить через TOPICS_DB_PATH в .env. Запускайте только один экземпляр бота. При удалении темы бот создаст новую при следующей отправке; закрытую тему откроет заново. Старые сообщения в General остаются на месте. Альбомы, как и раньше, отправляются отдельными файлами.

## Установка на существующий сервер

1. В целевой группе должны быть включены темы. Назначьте бота администратором с правом «Управление темами» и возможностью отправлять фото и видео.
2. Остановите службу: `sudo systemctl stop ck-nnov-bot`.
3. Сохраните резервную копию старого `/opt/ck_nnov_bot/bot.py`. Скопируйте новые **bot.py и topics.py** из этой папки в `/opt/ck_nnov_bot/`. Существующие `.env`, `venv`, настройки службы и базу тем не заменяйте. Зависимости не изменились.
4. Запустите: `sudo systemctl start ck-nnov-bot`.
5. Проверьте: `sudo systemctl status ck-nnov-bot`. При ошибке: `sudo journalctl -u ck-nnov-bot -n 50 --no-pager`.
6. Отправьте боту в личку фото, видео и кружочек: все должны попасть в одну новую тему. От другого аккаунта — в другую. После перезапуска службы отправка должна продолжиться в прежнюю тему.

Бот обрабатывает только личные сообщения, чтобы не отвечать на сообщения и служебные события в группе. Если доставка не удалась, пользователь получает сообщение об ошибке вместо подтверждения успеха.

Локальные проверки с имитацией Telegram: `python -m unittest -v test_bot.py` (после установки requirements.txt). Реальная отправка на сервере в рамках подготовки обновления не выполнялась.

Документация API: https://docs.aiogram.dev/en/v3.13.1/api/methods/create_forum_topic.html
